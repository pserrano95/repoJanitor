# Code of conduct

We are committed to a respectful, harassment-free project for everyone. Be constructive, assume good intent, critique ideas rather than people, and respect privacy and security boundaries.

Unacceptable behavior includes harassment, discriminatory language, threats, publishing private information, or intentionally compromising project or user security. Maintainers may edit or remove contributions and restrict participation when necessary to protect the community.

Report conduct concerns privately to the maintainer contact configured in the GitHub repository. Reports will be reviewed promptly and handled as confidentially as practical.
